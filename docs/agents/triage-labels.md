# Triage labels

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting for reporter information |
| ready-for-agent | ready-for-agent | Specified and eligible for agent work |
| ready-for-human | ready-for-human | Human implementation needed |
| wontfix | wontfix | Will not be actioned |

Check the target repository's labels before applying them. Use the existing label mapped to each role. Create a missing label only when authorized, and report the missing setup if it blocks the operation.
Labels do not independently authorize implementation or delegation.
